## 📖 第一部分：贪心算法与双指针（P1094 纪念品分组）

**核心思想**：为了让分组数最少，最贵的纪念品一定要尽量和最便宜的凑单。如果最贵的加上最便宜的超出上限，说明最贵的只能自己一组。

### 1. 核心代码逻辑
```c
// 1. 必须先升序排序
qsort(arr, n, sizeof(arr[0]), cmp);

int left = 0;
int right = n - 1;
int group = 0;

// 2. 双指针夹击
while(left <= right) {
    if(arr[left] + arr[right] > w) {
        // 最贵的配不上最便宜的，最贵的单飞
        group++;
        right--; 
    } else {
        // 能配上，一起走
        group++;
        left++;
        right--;
    }
}
```

### 2. `qsort` 终极避坑指南（极其重要！）
- **`sizeof` 陷阱**：
  - ❌ `sizeof(arr)`：这会算出整个数组的总字节数（30000*4），导致 `qsort` 跨步太大，程序崩溃！
  - ❌ `sizeof(struct)`：报语法错误，`struct` 不是完整类型。
  - ✅ `sizeof(arr[0])`：最标准、最安全的写法，算出单个元素的真实大小。
- **防溢出比较法**：
  - ❌ `return p1 - p2;`（极大数减极小数会溢出变成负数，导致排序混乱）。
  - ✅ `return (p1 > p2) - (p1 < p2);`（只算 1-0 或 0-1，绝对不溢出）。

## 📖 第二部分：二维数组与八方向遍历（P2670 扫雷游戏）

**工程思维**：遍历周围 8 个格子，不需要写 8 个 `if`，用偏移量 `dx` 和 `dy` 的双层循环即可。

### 1. 核心代码模板
```c
for (int dx = -1; dx <= 1; dx++) {
    for (int dy = -1; dy <= 1; dy++) {
        int nx = i + dx;
        int ny = j + dy;
        
        // 核心边界防护：绝对不能越界！
        if (nx >= 0 && nx < n && ny >= 0 && ny < m) {
            // 安全操作...
        }
    }
}
```

### 2. 字符二维数组的输入坑
- **无空格输入（如 `*??`）**：直接一行一行读，用 `scanf("%s", map[i]);`。因为 `%s` 遇到换行会自动停止，极其方便。
- **有空格输入（如 `* ? ?`）**：必须用两层循环，并且 `scanf(" %c", &map[i][j]);` 在 `%c` 前面**加一个空格**，用于吃掉换行符和空格。

## 📖 第三部分：字符串进制转换（P2084 多项式转换）

**核心痛点**：输入的 \(N\) 可能高达 1000 位，必须用字符串 `char[]` 接收，不能当 `int` 读。

### 1. 字符转数字的魔法
```c
int val = n[i] - '0'; // 将字符 '5' 变成真实的数字 5
```
- **原理**：字符 `'5'` 的 ASCII 码是 53，字符 `'0'` 是 48。`53 - 48 = 5`。必须在字符串处理中死死记住这个操作。

### 2. 格式控制标志位
```c
int is_first = 1;
// 循环内部：
if (val == 0) continue; // 系数为 0 的项跳过
if (is_first == 0) printf("+"); // 非第一项前面加加号
printf("%d*%d^%d", val, m, exp);
is_first = 0; // 第一项打印后，标志位置为 0
```

## 📖 第四部分：数组查表法（P5716 月份天数）

**工程思维**：比起写一长串的 `if-else`，直接建一个数组，用下标查表是最高效的。

```c
int day[13] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
// 闰年判断（完整版，防整百年坑）
if ((y % 4 == 0 && y % 100 != 0) || (y % 400 == 0)) {
    day[2] = 29;
}
printf("%d", day[m]);
```

## 🧠 今日踩坑复盘
1. **漏写 `#include <stdlib.h>`**：用 `qsort` 必须加这个头文件，否则直接 CE（编译错误）。
2. **输出格式错误**：把 `%d` 敲成了 `$d`，导致直接 WA（答案错误）。考场上极其容易犯这种低级失误。
3. **数组类型写错**：把存字符的二维数组定义成了 `int map[105][105]`，导致 `%s` 读入时直接内存错乱。
4. **C语言不能连等**：写 `m == 1 || 3 || 5` 是错的，必须写 `m == 1 || m == 3 || m == 5`。
