## 📖 第一部分：C语言 `for` 循环详解

### 1. 什么是 `for` 循环？
`for` 循环是用来“重复干活”的工具。基本结构是：
```c
for (初始化; 循环条件; 变量更新) {
    // 循环体（要重复执行的代码）
}
```

### 2. 核心语法拆解（以 1 到 100 求和为例）
```c
for (int i = 1; i <= 100; i++) {
    sum = sum + i;
}
```
- `int i = 1;`：准备好计数器 `i`，初始值为 1。
- `i <= 100;`：每次循环前检查，如果 `i <= 100`，才继续执行。
- `i++`：每次循环结束，`i` 自动加 1。
- `sum = sum + i;`：累加操作。一开始 sum 是 0，循环下来变成 0+1+2+3... +100。

### 3. 用循环求“1到100的奇数和”
```c
#include <stdio.h>

int main() {
    int sum = 0;

    for (int i = 1; i <= 100; i += 2) { // 注意：这里是 i += 2
        sum = sum + i;
    }

    printf("从1到100的奇数和为: %d\n", sum); // 注意：这里是 \n
    return 0;
}
```
**运行结果**：从1到100的奇数和为: 2500

## 🧠 第二部分：今日踩坑记录（极其重要！）

1. **`i + 2` 和 `i += 2` 的区别（致命逻辑错）**
   - `i + 2`：只是算了一下，没有重新赋值给 `i`。所以 `i` 永远是 1，循环变成死循环。
   - `i += 2`：相当于 `i = i + 2`。循环每跑一次，`i` 增加 2，这样才能正确跳过偶数。

2. **`\n` 和 `n` 的区别（致命语法错）**
   - 换行符是反斜杠加字母 n：`\n`。
   - 如果不小心打成了纯字母 `n`，编译器会报错 `未定义标识符 "n"`，因为它以为 `n` 是一个变量。

3. **终端卡住了怎么办？**
   - 如果终端执行命令没反应，第一步永远是看 VS Code 左侧的 **“问题”面板**（有红字提醒），那里往往已经告诉你了错误在哪一行。
   - 如果确认卡死，按 `Ctrl + C` 强制终止。

4. **C语言和C++的编译命令绝不能混用**
   - C语言（.c）用 `gcc` 编译。
   - C++（.cpp）用 `g++` 编译。

## 📂 第三部分：Linux 路径与 `~` 的含义（极其重要）

### 1. `~` 到底代表什么？
在 Linux 终端里，`~` 是一个极其常用的快捷键符号，它代表**当前用户的主文件夹（Home Directory）**。
- 我的用户名是 `kylin`，所以 `~` 翻译成完整路径就是 `/home/kylin`。
- **举例**：你输入 `cd ~/code`，电脑理解的就是 `cd /home/kylin/code`。

### 2. 为什么会报错 `No such file or directory`？
- 当你处在 `~/code` 目录时，输入 `cd ~/04_C_Class` 会报错，因为 `~` 会把你拉回 `/home/kylin`，那个目录下根本没有 `04_C_Class` 文件夹（它在 `code` 里面）。
- **正确的做法**：既然你已经在 `~/code` 里面了，直接敲 `cd 04_C_Class` 即可（不要加波浪号）。
- **偷懒小技巧**：敲 `cd` 加空格，然后按几次键盘上的 `Tab` 键，系统会自动帮你补全文件夹名字，避免拼写错误。

### 3. 如何用 Windows 资源管理器查看 Linux 文件？
- 在 Linux 终端输入：`explorer.exe .` （注意最后有一个点）。
- 这会弹出一个 Windows 文件夹窗口，路径类似 `网络 > wsl.localhost > Ubuntu > home > kylin > code`。
- **⚠️ 警告**：这个窗口只用来“看”，**绝对不要在这里重命名、拖拽或删除文件**，跨系统操作极容易导致 Linux 权限错误或 Git 崩溃。写代码永远在 VS Code 里进行。

## 🌐 第四部分：HTML零基础破冰（前端起点）

### 1. 核心概念：网页的“三剑客”
- **HTML**：结构（毛坯房，决定网页上有什么）。
- **CSS**：样式（装修，决定网页好不好看）。
- **JavaScript**：行为（自动化设备，决定网页能不能动、能不能算）。

### 2. 第一个网页的骨架结构
```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>我的第一个网页</title>
</head>
<body>
    <h1>我是一个大一新生</h1>
    <p>今天我开始正式学习 HTML 了。</p>
    <ul>
        <li>我学会了用 h1 写标题</li>
        <li>我学会了用 p 写段落</li>
        <li>我学会了用 ul 和 li 写列表</li>
    </ul>
</body>
</html>
```

### 3. HTML的关键学习点（不需要背，会用就行）
- **标签**：如 `<h1>内容</h1>`，包裹起来的东西会被浏览器渲染。
- **属性**：比如 `<a href="https://www.baidu.com">百度</a>`，`href` 是用来控制跳转链接的。
- **图片**：用 `<img src="图片路径" alt="描述">` 展示图片。
- **引入JS**：用 `<script src="js.js"></script>` 把JS文件引入进网页，实现互动功能。

### 4. 🚀 如何在 WSL 里运行 HTML 网页？（Live Server 实战）
**铁律：绝对不要在 WSL 终端里用 `gcc` 或 `g++` 去编译网页！网页不需要编译！**

**正确流程：**
1. 在 VS Code 左侧点击“扩展”图标，搜索 `Live Server`，点击“在 WSL: Ubuntu 中安装”。
2. 打开你要预览的 `index.html` 文件。
3. 在代码编辑区**右键**，选择 **`Open with Live Server`**（或者点右下角的 `Go Live`）。
4. VS Code 会弹出一个提示框：“**在端口 5500 上运行的应用程序可用**”，点击蓝色的 **“在浏览器中打开”**。
5. 如果浏览器打开后显示的是“文件夹列表”（如 00_Notes, 01_C++ 等），说明你是在**根目录**启动了服务，而不是在具体的文件上。只需要在浏览器里点击进入 `05_Web` 文件夹，再点击 `index.html` 即可看到真实网页。
6. 也可以直接在浏览器地址栏输入 `http://localhost:5500` 来访问。
