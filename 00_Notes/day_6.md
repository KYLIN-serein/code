## 📖 第一部分：C语言核心逻辑——数组反转

**目标**：把数组里的元素首尾对调（如 `1 2 3 4 5` 变成 `5 4 3 2 1`）。

### 1. 核心代码
```c
#include <stdio.h>

int main() {
    int arr[5];
    printf("请输入5个整数: ");
    for (int i = 0; i < 5; i++) {
        scanf("%d", &arr[i]);
    }

    // 核心逻辑：首尾交换
    for (int i = 0; i < 5 / 2; i++) {
        int temp = arr[i];            // 1. 把左边的数存到临时变量
        arr[i] = arr[4 - i];          // 2. 把右边的数放到左边
        arr[4 - i] = temp;            // 3. 把临时变量放到右边
    }

    printf("反转后的结果是: ");
    for (int i = 0; i < 5; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
    return 0;
}
```

### 2. 硬核解析
- **为什么要用 `temp`（空杯子）？** 交换两个变量的值，必须借用一个临时变量。如果直接覆盖，原来的数据就会永久丢失。
- **为什么循环条件是 `5 / 2`？** 因为交换是首尾同时进行的（0和4换，1和3换）。如果循环5次，走到后面又把数字换回去了。只需要交换数组长度的一半即可。

## 📖 第二部分：C语言必会算法——冒泡排序

**目标**：把数组里的数字从小到大排序。这是算法竞赛的基石。

### 1. 核心代码
```c
#include <stdio.h>

int main() {
    int arr[5] = {5, 2, 4, 1, 3}; // 乱序数组

    // 外层循环：控制比较的趟数
    for (int i = 0; i < 5 - 1; i++) {
        // 内层循环：控制每趟比较的次数
        for (int j = 0; j < 5 - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                // 如果前一个比后一个大，就交换
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }

    printf("从小到大排序后的结果: ");
    for (int i = 0; i < 5; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
    return 0;
}
```

### 2. 硬核解析
- **外层循环 `i < 5 - 1`**：5 个数只需要比较 4 趟。每比较一趟，最大的那个数就会像泡泡一样“沉”到最右边。
- **内层循环 `j < 5 - 1 - i`**：每过一趟，右边就会多一个排好序的数字，所以内部的比较次数可以逐趟减少（减去 `i`）。

今天正式入驻洛谷（luogu.com.cn），开启了算法竞赛的实战之路。

### 1. 洛谷提交的“三大铁律”
1. **绝对不要写任何提示语**：像 `printf("请输入...");` 绝对不能写。机器自动判卷，多打一个字就会判 `WA`（Wrong Answer）。

3. **别用 `system("pause")`**。

### 2. 今日踩坑：P1000（超级玛丽游戏）
- **错误现象**：直接 `printf("` 后按了回车换行，导致 `Compile Error`（编译错误）。
- **原因**：C 语言的字符串**不允许直接跨行**。
- **解决**：必须在每一行的末尾用 `\n` 来换行，或者写多个 `printf`。

## 🛠️ 第四部分：函数初体验（模块化思维）

把特定的功能打包成一个“小分队”，方便重复调用。

### 1. 核心代码：求最大值函数
```c
#include <stdio.h>

// 定义函数：返回类型 函数名(参数列表)
int getMax(int a, int b) {
    if (a > b) {
        return a; // 把结果交出去，函数结束
    } else {
        return b;
    }
}

int main() {
    int x = 10, y = 25;
    int max_val = getMax(x, y); // 调用函数，接收结果
    printf("最大值是: %d\n", max_val);
    return 0;
}
```

## 🔤 第五部分：字符与 ASCII 码底层逻辑

### 1. `%c` 是什么？
专门用来读取/打印**单个字符**（如字母、符号）的占位符，对应 `char` 类型。

### 2. 字符本质上就是整数！
在计算机底层，字符就是数字（ASCII 码）。
- 大写字母 `A` 是 **65**，小写字母 `a` 是 **97**。它们之间刚好差 **32**。
- 所以，将小写转大写，只需减去 32：`ch - 32`。

### 3. 能不能用 `int` 存字符？
**完全可以！** `char` 本质是 1 个字节的 `int`。如果你用 `int ch;` 结合 `%c` 接收，完全没问题。
但在实战中，**建议遵循类型规范**，存字符就用 `char`，存大数字就用 `long long`，省空间且代码可读性强。

## 📦 第六部分：C语言数据类型“盒子”大全

不同的数据，用不同大小的盒子装。

| 盒子类型 | 占据空间 | 能装什么 | 占位符（scanf/printf） | 适用场景 |
| :--- | :--- | :--- | :--- | :--- |
| **`char`** | 1 字节 | 单个字符 | **`%c`** | 处理字母、符号（本质是 -128~127 的整数）。 |
| **`int`** | 4 字节 | 约正负21亿的整数 | **`%d`** | 最常用的主力整数盒子。 |
| **`long long`** | 8 字节 | 约正负900亿亿 | **`%lld`** | 遇到 `10^18` 级别的超大数时必用。 |
| **`float`** | 4 字节 | 小数（6-7位精度） | `%f` | 精度要求不高时用，竞赛不推荐。 |
| **`double`** | 8 字节 | 小数（15-16位精度） | **`%lf`(输入)**<br>**`%f`(输出)** | **最常用的浮点盒子**，算除法、面积必用。 |

**⚠️ 经典踩坑**：如果是大整数运算，Pascal 的 integer 会爆，C/C++ 的 `int` 顶不住时，一定要立刻换 `long long`。
