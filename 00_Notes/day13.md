## 📖 第一部分：通讯录 V3.0 文件持久化闭环

**工程背景**：内存里的数据一断电就会灰飞烟灭。要想把数据永久保存到硬盘，必须通过 `FILE` 指针来操作文件。

### 1. 文件操作核心函数
- **`fopen("文件名", "模式")`**：
  - `"r"`（只读）：如果文件不存在，返回 `NULL`（不会报错崩溃）。
  - `"w"`（只写）：如果文件不存在，自动创建；如果存在，**无情清空原内容**。
- **`fprintf(fp, ...)`**：将数据写入文件。
- **`fscanf(fp, ...)`**：从文件读取数据。
- **`fclose(fp)`**：**极其重要！** 必须关闭文件，否则数据可能还在缓冲区，没真正写进硬盘。

### 2. 今日致命踩坑复盘：括号错位
- **错误代码**：`while(fscanf(fp, "%s %d"), book[count].name, &book[count].age != EOF)`
- **原因**：`fscanf` 的右括号提前闭合了！导致后面的变量成了孤立代码，编译器报 `%s` 找不到 `char *`，`%d` 找不到 `int *`。
- **正确写法**：
  ```c
  while(count < 100 && fscanf(fp, "%s %d", book[count].name, &book[count].age) == 2) {
      count++;
  }
  ```
  *(注：用 `== 2` 判断成功读取了名字和年龄两个参数，比用 `!= EOF` 更安全，防死循环)*

## 🧠 第二部分：传智杯冲刺 —— 多组输入与字符串

### 1. 必杀技：`EOF` 多组输入
在 ACM 赛制中，经常要求处理“多组数据直到文件结束”。
```c
while (scanf("%d %d", &a, &b) != EOF) {
    printf("%d\n", a + b);
}
```
- **本地测试结束方法**：在终端按 `Ctrl + D`（Linux/WSL）或 `Ctrl + Z`（Windows）来模拟文件结束。

### 2. 字符串逐字符读取（P5015 标题统计）
- **痛点**：`scanf("%s")` 遇到空格就罢工，无法统计带空格的整行句子。
- **解药**：用 `getchar()` 一个一个字符吃。
```c
while ((ch = getchar()) != '\n') {
    if ((ch >= 'a' && ch <= 'z') || (ch >= 'A' && ch <= 'Z') || (ch >= '0' && ch <= '9')) {
        count++;
    }
}
```
- **坑点**：`ch = getchar()` 外面必须套括号，因为 `!=` 优先级高于 `=`。

## 🏆 第三部分：传智杯冲刺 —— `qsort` 与贪心算法

### 1. `qsort` 快速排序模板（必背）
```c
#include <stdlib.h>

int cmp(const void *a, const void *b) {
    struct water *p1 = (struct water *)a; // 强转回结构体指针
    struct water *p2 = (struct water *)b;
    
    if (p1->time != p2->time) {
        return p1->time - p2->time; // 升序
    } else {
        return p1->id - p2->id;     // 时间相同按编号升序
    }
}
// 调用
qsort(arr, n, sizeof(struct water), cmp);
```
- **参数解释**：`qsort(首地址, 元素个数, 单个元素大小, 比较规则函数)`。
- **排序口诀**：
  - `p1 - p2` = 升序（从小到大，小的排前面）。
  - `p2 - p1` = 降序（从大到小，大的排前面）。

### 2. 贪心算法初体验（P1223 排队接水）
- **贪心思想**：让接水时间最短的人先接，后面人的总等待时间最短。
- **工程实现**：先用 `qsort` 按时间升序排好队，再开始计算等待时间。不要在输入时算等待时间，因为队伍还没排好。
- **致命坑点（数据溢出）**：总等待时间可能会极大，必须用 `long long` 存。
```c
long long current_wait = 0; // 记录前面人打水的总时间
double total_sum = 0;
for (int i = 0; i < n; i++) {
    total_sum += current_wait; // 当前人的等待时间
    current_wait += arr[i].time; // 更新总耗时
}
printf("%.2f", total_sum / (double)n);
```
