## 📖 第一部分：知识大融合——学生成绩分析系统

**目标**：将“输入、找最大值、排序、输出”全部封装进不同的函数，告别把所有代码都塞在 main 里的坏习惯。

### 1. 核心代码 (`score_system.c`)
```c
#include <stdio.h>

// 函数1：找最大值（打擂台法）
int getMax(int arr[], int n) {
    int max = arr[0];
    for (int i = 1; i < n; i++) {
        if (arr[i] > max) {
            max = arr[i];
        }
    }
    return max;
}

// 函数2：冒泡排序
void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}

int main() {
    int scores[5];
    
    printf("请输入5个学生的成绩: ");
    for (int i = 0; i < 5; i++) {
        scanf("%d", &scores[i]);
    }

    int max_score = getMax(scores, 5);
    printf("最高分是: %d\n", max_score);

    bubbleSort(scores, 5);

    printf("成绩从小到大排序为: ");
    for (int i = 0; i < 5; i++) {
        printf("%d ", scores[i]);
    }
    printf("\n");

    return 0;
}
```

### 2. 硬核解析（极其重要）
- **数组传参**：`getMax(scores, 5)`。把数组传给函数时，**传的是数组的首地址**。所以 `bubbleSort` 函数内部把数组排序后，`main` 函数里的原数组也会发生改变（这是指针的雏形）。
- **`int` 函数 vs `void` 函数**：`getMax` 前面是 `int`，说明它必须 `return` 一个结果；`bubbleSort` 前面是 `void`，说明它只负责干活，不需要交出结果。

## 📖 第二部分：新知识——二维数组与矩阵

一维数组是一排房间，**二维数组就是一栋楼（有行有列）**。定义方式：`int arr[行数][列数]`。

### 1. 核心代码 (`matrix.c`)：求 3x3 矩阵主对角线之和
```c
#include <stdio.h>

int main() {
    // 定义一个 3 行 3 列的二维数组
    int matrix[3][3];
    int sum = 0;

    printf("请输入 3x3 矩阵的 9 个数字:\n");
    // 接收输入：必须用双重循环
    for (int i = 0; i < 3; i++) {       // 外层循环控制“行”
        for (int j = 0; j < 3; j++) {   // 内层循环控制“列”
            scanf("%d", &matrix[i][j]);
        }
    }

    // 计算主对角线元素之和 (行号等于列号的元素：0,0  1,1  2,2)
    for (int i = 0; i < 3; i++) {
        sum = sum + matrix[i][i];
    }

    printf("主对角线元素之和为: %d\n", sum);
    return 0;
}
```

### 2. 硬核解析
- **双重循环输入**：`for(i)` 控制行，`for(j)` 控制列。当 `i=0` 时，内层 `j` 循环 3 次，刚好填满第一行。
- **主对角线特征**：主对角线（左上到右下）的坐标特征是 **行号等于列号**（`i == j`）。所以不需要两层循环，只需要一层 `for(int i=0; i<3; i++)` 然后累加 `matrix[i][i]` 即可。

## 🧠 第三部分：今日踩坑与调试经验

今天运行 `matrix.c` 时，输入：
```text
1 2 3
4 5 6
7 8 9
```
程序输出了 `14`，而不是正确的 `15`。

**排查结果**：
- 代码逻辑是 **100% 正确**的。
- 原因在于终端手动输入时的“幽灵失误”（可能是不小心漏敲了一个数字，或者多敲了一个空格导致数据错位）。
- 后来把 `1 2 3 4 5 6 7 8 9` 放在一行输入，完美输出 `15`。

**知识点补充**：
`scanf("%d")` 会自动忽略所有的空格和回车。所以无论你是按 9 次回车，还是按 8 次空格最后按 1 次回车，只要数字的个数和顺序对，结果就不会错。如果在终端运行时结果诡异，先检查是不是自己手滑输错了。
