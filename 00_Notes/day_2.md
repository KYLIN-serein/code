## 📖 第一部分：C++ 数据类型与核心概念

### 1. 三大基础“盒子”（数据类型）
C++ 是强类型语言，使用变量前必须指定类型：
- **`int`**：装整数（如 `5`、`100`）。
- **`double`**：装小数（如 `3.14`、`5.0`）。**注意：`5 / 2` 会得到 `2`，必须写成 `5.0 / 2` 才能得到 `2.5`。**
- **`char`**：只能装**一个**字符（如 `'+'`、`'-'`），必须用**单引号**。

### 2. 变量声明与初始化（防坑指南）
- 只写 `int a;` 不赋值，输出时会变成随机垃圾数字（内存残留）。
- **好习惯**：声明时就给它一个干净的值，如 `double num1 = 0.0;` 或 `char op = ' ';`。

### 3. `cout` / `cin` 配合使用
- **`std::cout`**：像服务员，负责输出。输出变量时直接写变量名（如 `std::cout << num1;`），输出文字时加双引号。
- **`std::cin`**：像顾客，负责接收键盘输入（如 `std::cin >> num1;`）。
- **配合秘诀**：先用 `cout` 打印提示语（如 `"请输入第一个数字: "`），**不要在末尾加 `\n`**，然后紧跟 `cin >>` 等待用户输入。

### 4. `int` / `char` / `double` 的值传递
- `=` 是赋值，会覆盖旧值。
- `>>` 尖角朝向右边（`cin >> a`），表示数据从键盘流向变量。
- `<<` 尖角朝向左边（`cout << a`），表示数据从变量流向屏幕。

### 5. 单引号 vs 双引号
- `' '`（单引号）：装单个字符（`char` 类型）。
- `" "`（双引号）：装一串字符（字符串），用于 `cout` 或 `std::string`。

### 6. `std::string`（字符串大盒子）
- 使用前需引入 `#include <string>`。
- 能装一串文字（如名字）。
- 遇到带空格的名字，要用 `std::getline(std::cin, name);` 代替 `cin >>`。

### 7. `#include` 的作用
- 这是“复制粘贴”指令，告诉电脑去标准库拿工具箱。
- `<iostream>`：输入输出工具箱（`cin`、`cout`）。
- `<string>`：字符串工具箱。
- `<cmath>`：数学工具箱（`sqrt`开平方、`pow`次方）。
