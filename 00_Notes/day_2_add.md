## 📖 第一部分：C 语言与 C++ 的核心区别
C++ 是 C 语言的升级版（自动挡），C 语言是基础版（手动挡）。目前阶段，我们需要适应 C 语言的硬核操作，千万别把两门语言的语法搞混。

| 对比项 | C 语言（手动挡） | C++（自动挡，我们之前学的） |
| :--- | :--- | :--- |
| **工具箱（头文件）** | #include <stdio.h> | #include <iostream> |
| **打印输出** | printf("内容"); | std::cout << "内容"; |
| **接收输入** | scanf("%d", &num); | std::cin >> num; |
| **文字字符串** | 只能用字符数组 | 有极其方便的 std::string |
| **编译命令** | gcc 源文件.c -o 目标名 | g++ 源文件.cpp -o 目标名 |

## 🛠️ 第二部分：stdio.h 是什么？
- 全称：Standard Input Output（标准输入输出）。
- 后缀 .h 代表 Header file（头文件）。
- 里面装着 C 语言最基础的两个工具：printf（打印到屏幕）和 scanf（接收键盘输入）。
- 注意：C 语言的工具箱后缀都是 .h，而 C++ 的新工具箱通常没有后缀。

## 📦 第三部分：数据类型与格式占位符（极其重要！）

C 语言用不同的“盒子”装数据，输出和输入时必须使用对应的“扫码枪”（占位符 %）。

| 数据类型 | 对应盒子 | 打印/输出（printf） | 接收/输入（scanf） |
| :--- | :--- | :--- | :--- |
| **整数** | int num = 0; | %d | %d |
| **小数（双精度）** | double num = 0.0; | %f 或 %.1f %.2f | 必须写 %lf（加小写L） |
| **小数（单精度）** | float num = 0.0f; | %f | %f |

### 🎯 深度解析：%d、%f、%lf、%.2f
1. **%d**：代表十进制整数（decimal）。只能给 int 用。
2. **%f**：代表浮点数（float）。打印 double 时默认输出 6 位小数。如果你想保留 1 位或 2 位，写成 %.1f 或 %.2f（只能在 printf 里用！不能在 scanf 里用）。
3. **%lf**：代表 long float（双精度浮点数）。只用在 scanf 接收 double 的时候。它不限制小数位数，用户输入 3.14159 它也能完整接住。它只管盒子的大小，不管位数。
4. **% 号的本质**：它是一个“占位符”。当电脑看到 %f，它就知道“这里要放一个小数”，然后去后面找对应的变量（比如 num），把盒子里的值提取出来打印。
5. **⚠️ 致命坑点**：float 能装整数吗？能，但是非常不建议。因为 float 只有 4 个字节，精度只有 6-7 位，存放很大的整数会发生数据失真。整数无脑用 int，小数无脑用 double。

## 💻 第四部分：代码实战与逐句解析

### 代码 1：判断整数正负（judge_num.c）
```c
#include <stdio.h>

int main() {
    int num = 0;

    printf("请输入一个整数: ");
    scanf("%d", &num); // 注意：& 是取地址符，千万别漏！

    if (num > 0) {
        printf("这是一个正数\n");
    } else if (num < 0) {
        printf("这是一个负数\n");
    } else {
        printf("这是零\n");
    }

    return 0;
}
```

**逐句大白话解析：**
1. `#include <stdio.h>`：拿来 C 语言的基础工具箱。
2. `int main() {`：程序大门，所有代码从这里执行。
3. `int num = 0;`：准备一个整数盒子 `num`，初始值放 `0`。
4. `printf(...)`：屏幕打字，末尾不加 `\n`，光标停在冒号后等用户输入。
5. `scanf("%d", &num);`：程序暂停，等用户输入。`%d` 告诉电脑“我要整数”，`&num` 告诉电脑“把输入的数字塞进 `num` 盒子的地址里”。
6. `if (num > 0) { ... }`：如果 `num` 大于 0，就打印“正数”。
7. `else if (num < 0) { ... }`：如果不大于 0，再检查是不是小于 0，是就打印“负数”。
8. `else { ... }`：如果前面都不成立，那剩下唯一可能就是 0，打印“这是零”。
9. `return 0; }`：任务顺利完成，结束程序。

### 代码 2：小数测试（test_float.c）
```c
#include <stdio.h>

int main() {
    double num = 0.0;
    
    printf("请输入一个小数: ");
    scanf("%lf", &num); // 接收double，必须用 %lf
    
    printf("默认打印（6位小数）: %f\n", num);    // 输出6位小数
    printf("保留2位小数: %.2f\n", num);          // 输出2位小数
    printf("保留1位小数: %.1f\n", num);          // 输出1位小数
    
    return 0;
}
```
**逐句解析：**
1. `double num = 0.0;`：准备一个小数盒子，初始值 0.0。
2. `scanf("%lf", &num);`：接收用户输入的小数。**注意这里用的是 `%lf`，因为盒子是 double**。输入时用户爱输几位小数就输几位。
3. `printf("默认打印（6位小数）: %f\n", num);`：用 `%f` 输出，电脑默认给你显示 6 位小数。
4. `printf("保留2位小数: %.2f\n", num);`：用 `%.2f` 控制输出格式，只显示 2 位小数。
5. `printf("保留1位小数: %.1f\n", num);`：用 `%.1f` 控制输出格式，只显示 1 位小数。
6. 总结：输入时 `%lf` 会完整保存小数，输出时 `%.2f` 只负责改变显示的样子，不改变盒子里的存储值。


## 🧠 今日踩坑记录（考前必背）

1. **漏分号**：C 语言每条完整语句结尾必须加 `;`。漏了以后，编译器会把下一行也算作上一行，报错行号会非常诡异（比如在第6行报错，其实是第4行缺分号）。
2. **漏取地址符 `&`**：在 `scanf` 里输入普通变量，**必须**写 `&num`。漏了程序在 Linux 下编译不报错，但运行时会直接崩溃，报 **`Segmentation fault (段错误)`**。这是新手死亡陷阱。
3. **`%d` 和 `%f` 混用**：用 `int` 盒子接 `%f`，或者用 `double` 盒子接 `%d`，程序会输出莫名其妙的乱码。扫码枪和包裹必须严格匹配。
4. **C 和 C++ 语法弄混**：`04_C_Class` 里全都是 `.c` 文件，用 `gcc` 编译；`01_C++` 里全是 `.cpp` 文件，用 `g++` 编译。C 语言里不要写 `std::cout`。
5. **文件夹规划**：为了避免混乱，现在 C 语言放在 `04_C_Class`，Java 放在 `03_java`，C++ 放在 `01_C++`。写代码前务必确认自己当前在哪个文件夹。
