## 📖 第二部分：算法边界排错（P1308 统计单词数）

**核心痛点**：`strstr` 只能找子串，不能精准找单词（比如找 `to`，会把 `today` 也算进去）。

### 1. 左右边界“护法”判断法
```c
char *p = article;
while ((p = strstr(p, word)) != NULL) {
    // 核心排错：检查前后边界！
    int left_ok = (p == article) || (*(p - 1) == ' '); // 左边是开头或空格
    int right_ok = (*(p + len_w) == ' ') || (*(p + len_w) == '\n') || (*(p + len_w) == '\0'); // 右边是空格、换行或结束
    
    if (left_ok && right_ok) {
        count++;
        // 记录首次出现位置...
    }
    p++; // ⚠️ 极其关键：指针往前走一步，防止死循环！
}
```
- **指针 `p` 的作用**：相当于手指头，指向 `strstr` 找到的首字母地址。
- **`p++` 的意义**：如果找到了一个无效匹配（如 `today` 的 `to`），必须让指针走一步，让警犬继续往后找，否则原地死循环。

## 📖 第三部分：质数判断与输出格式（P5723 质数口袋）

**核心痛点**：数学边界条件的临界值，以及洛谷极其严格的输出格式。

### 1. 质数判断的“等于号”陷阱
```c
// ❌ 错误写法：如果是 9，i=3 时 3*3 < 9 为假，直接判断 9 是质数
for(int i = 2; i * i < n; i++) 

// ✅ 正确写法：必须加等于号，防止完全平方数漏判
for(int i = 2; i * i <= n; i++) {
    if(n % i == 0) return 0;
}
```

### 2. 输出格式铁律
- **洛谷没有废话**：该换行必须换行，该加空格必须加空格。
- 题目要求每个质数独占一行，如果写成 `printf("%d", i);` 会直接 WA。必须写 `printf("%d\n", i);`。
