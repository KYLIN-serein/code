## 📖 第一部分：Markdown 语法完全指南（记笔记专用）

Markdown 不是编程语言，它是专门用来写笔记、写文档的“极简排版工具”。不需要背，记住下面这几个最常用的符号即可：

### 1. 标题（用 # 号表示）
在行首输入 `#` 加空格，代表一级标题。
- `# 一级标题`
- `## 二级标题`
- `### 三级标题`
*（每多一个 #，字号就小一级，最多六级）*

### 2. 字体样式
- **加粗**：文字两边各加两个星号 `**内容**`
- *倾斜*：文字两边各加一个星号 `*内容*`
- ~~删除线~~：文字两边各加两个波浪号 `~~内容~~`

### 3. 列表（用于罗列知识点）
- **无序列表**：在行首输入 `-` 加空格（或者 `*` 加空格）
- **有序列表**：在行首输入 `1.` 加空格（自动生成编号）

### 4. 代码与高亮（程序员的灵魂）
- **行内代码**：用反引号 `` ` `` 包裹，例如 `g++ calculator.cpp`，用于标注命令或变量名。
- **代码块**：用三个反引号 ` ``` ` 包裹，并写上语言名，例如：

```cpp
// 这里是代码块，语法会自动高亮
int a = 5;
```

### 5. 引用（用于记录报错信息或者名言）
在行首输入 `>` 加空格，例如：
> 遇到报错不要慌，先看终端英文提示。

### 6. 分割线（用于划分章节）
输入三个减号 `---` 并回车，就会生成一条长横线。

### 7. 如何预览 Markdown？
在 VS Code 中，写完笔记后按快捷键 **`Ctrl + K`**，松开后紧接着按 **`V`**，就能在右侧看到排版精美的网页效果。

## 💻 第二部分：今日代码练习与逐行拆解

今天是第一次写 C++，代码虽然短，但包含了“输入、输出、判断”的核心逻辑。

### 📄 完整代码：

```cpp
#include <iostream>

int main() {
    int a, b;
    char op;

    std::cout << "请输入表达式 (例如: 3 + 5): ";
    std::cin >> a >> op >> b; // 接收用户输入

    if (op == '+') {
        std::cout << "结果: " << a + b << "\n";
    } else if (op == '-') {
        std::cout << "结果: " << a - b << "\n";
    } else {
        std::cout << "暂不支持该运算符\n";
    }

    return 0;
}
```

### 🔍 逐句拆解教程：

#### 1. `#include <iostream>`
- **作用**：这是告诉编译器去“图书馆”借一个叫 `iostream` 的工具箱。`i` 代表 input（输入），`o` 代表 output（输出），`stream` 是流。没有这一句，你后面的 `cin` 和 `cout` 都没法用。

#### 2. `int main() {`
- **作用**：这是程序的“大门”。`main` 是主函数，所有的 C++ 程序都从这里开始执行。前面的 `int` 表示这个函数执行完毕后会返回一个整数。左大括号 `{` 代表程序从这里开始。

#### 3. `int a, b;` 和 `char op;`
- **作用**：
  - `int a, b;`：在内存里申请两个整数类型的“小盒子”，分别叫 `a` 和 `b`。
  - `char op;`：申请一个字符类型的“小盒子”，叫 `op`（operation 的缩写），用来装 `+`、`-` 这样的运算符。

#### 4. `std::cout << "请输入表达式 (例如: 3 + 5): ";`
- **作用**：`std::cout` 是“标准输出”工具。`<<` 就像水流的方向，把后面的字符串 `"请输入表达式..."` 推到屏幕上。分号 `;` 代表这一句写完了。

#### 5. `std::cin >> a >> op >> b;`
- **作用**：这是整个程序最神奇的一句。`std::cin` 是“标准输入”工具。`>>` 是数据流进来的方向。当程序运行到这里时，它会停下来，等你用键盘输入。
- 如果你输入 `5 + 3`：它会自动把 `5` 装进 `a`，把 `+` 装进 `op`，把 `3` 装进 `b`。这比分别写三行输入代码简洁得多。

#### 6. `if (op == '+') {`
- **作用**：判断语句。看看 `op` 这个盒子里装的是不是 `+` 号。
- **⚠️ 绝对重点**：这里必须是两个等号 `==`。在 C++ 里，一个等号 `=` 是“赋值”（把右边塞给左边），两个等号 `==` 才是“判断相等”。写错一个符号，程序就会产生极其诡异的 bug。

#### 7. `std::cout << "结果: " << a + b << "\n";`
- **作用**：如果上面的条件成立，就把 `"结果: "` 推上屏幕，接着计算 `a + b`，把算出来的数字也推上屏幕，最后 `"\n"` 代表换行（相当于按了一下回车键，光标移到下一行）。

#### 8. `} else if (op == '-') {` 与 `} else {`
- **作用**：如果 `op` 不是 `+`，程序会接着往下看，是不是 `-` 呢？如果是，就输出减法结果。`else if` 就是“否则，如果……”的意思。最后的 `else` 是“否则”，如果既不是加也不是减，就输出“暂不支持该运算符”。这是一种防呆设计，防止别人乱输入。

#### 9. `return 0;` 与 `}`
- **作用**：`return 0;` 意思是告诉操作系统：“我的任务顺利完成了，没出问题。” 如果你前面遇到除数为0等严重错误，可以写 `return 1;` 来告诉系统“出错了”。最后的 `}` 是 `main` 函数的结束大括号。

## 🔣 第三部分：核心符号用法速查表

在 C++ 中，符号有着极其严格的含义，这也是新手最容易混淆的地方：

### 1. C++ 中的三大核心符号
- **`<<`（插入运算符/输出）**：把右边的数据“推”到左边的屏幕上。用法：`std::cout << "Hello" << 123;`
- **`>>`（提取运算符/输入）**：把键盘输入的数据“提取”到右边的变量里。用法：`std::cin >> a >> b;`
- **`==`（等于判断）**：判断两边是否相等。用法：`if (op == '+')`。**注意别写成单等号 `=`**。

### 2. C++ 中的其他常见符号
- **`//`（单行注释）**：// 后面的内容编译器会无视，用来写笔记。
- **`\n`（换行符）**：相当于按了一下键盘的“回车键”。
- **`;`（分号）**：C++ 每一条语句的结束符，就像写作文要加句号。漏了分号会报错。

### 3. Markdown 中的符号（用于写笔记）
- **` ``` `（三个反引号）**：用来包裹代码块，实现高亮。
- **`#`（井号）**：`# 一级标题`。
- **`-`（短横线）**：写在行首，代表无序列表。
