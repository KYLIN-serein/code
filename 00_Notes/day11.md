## 📖 第一部分：工程数据结构——结构体数组

**工程背景**：在真实软件中（如手机通讯录），如果只用普通的二维数组存人名，用另一个数组存年龄，数据会极其分散。**结构体数组**将每个联系人的信息打包，连成一块连续的内存空间。

### 1. 核心定义
```c
struct Contact {
    char name[20];
    int age;
};

struct Contact book[100]; // 申请 100 个联系人的大空间
```
- 内存分布：这 100 个 `Contact` 在内存里是连续排列的。
- 访问方式：`book[0].name` 表示第 0 个人的姓名，`book[i].age` 表示第 i 个人的年龄。

## 🧠 第二部分：今日致命踩坑复盘（极其重要）

### 踩坑 1：无限循环的 `scanf`
- **错误代码**：`for(int i = 0; i < 100; i++) { scanf("%s %d", ...) && count++; }`
- **现象**：用户输入了 3 个人后，程序不结束，依然在等待第 4 个人的输入。
- **原因**：死写循环上限为 100，`scanf` 只要没有遇到错误，就会一直阻塞等待用户敲键盘。
- **工程纠正**：实际开发必须有明确的结束条件（我们当前版本固定只录 3 个人测试）。

### 踩坑 2：输出序号全乱套
- **错误代码**：`printf("%d. 姓名...", count, ...)`
- **原因**：`count` 是总人数，如果录了 3 个人，序号就会全打印成 `3. 姓名...`
- **纠正**：应该使用当前遍历的下标 `i + 1`，这样才能输出 1、2、3。

## 💻 第三部分：通讯录 V1.0 完整代码

### 1. 核心代码 (`address_book.c`)
```c
#include <stdio.h>

struct Contact {
    char name[20];
    int age;
};

int main() {
    struct Contact book[100];
    int count = 3; // 当前版本固定录入3人
    int i;

    printf("--- 欢迎使用微型通讯录 ---\n");
    
    // 1. 接收输入
    for(i = 0; i < count; i++) {
        printf("请输入第 %d 个人的姓名和年龄: ", i + 1);
        scanf("%s %d", book[i].name, &book[i].age); 
    }

    // 2. 打印输出
    printf("\n--- 通讯录列表 ---\n");
    for(i = 0; i < count; i++) {
        printf("%d. 姓名: %-10s 年龄: %d\n", i + 1, book[i].name, book[i].age);
    }

    return 0;
}
```

### 2. 硬核解析与排版神器 `%-10s`
- **`%-10s`**：这是控制台输出的“排版神器”。意思是：输出一个字符串，左对齐（`-`号的作用），并且强制占用 10 个字符的宽度。
- 如果名字是“张三”（2个汉字占6字节），它会自动补4个空格；如果是“欧阳娜娜”（4个汉字），补2个空格。这样输出的列表就如同表格一样，极其整齐。
- **`book[i].name` 为何不加 `&`**：因为 `name` 本身就是一个字符数组，数组名就是首地址。而 `age` 是普通整数，必须加 `&`。
