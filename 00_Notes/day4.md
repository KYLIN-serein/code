## 📖 第一部分：C语言 `while` 循环详解

### 1. 什么是 `while` 循环？
`for` 循环适合“知道要循环多少次”的场景，而 `while` 循环适合“只要满足条件就一直做”的场景。
基本结构：
```c
while (循环条件) {
    // 循环体
}
```

### 2. `while` 循环重写 1 到 100 求和
```c
#include <stdio.h>

int main() {
    int sum = 0;
    int i = 1;  // 计数器写在循环外面

    while (i <= 100) {
        sum = sum + i;
        i++;    // ⚠️ 致命重点：千万别忘了这行！
    }

    printf("1到100的和是: %d\n", sum);
    return 0;
}
```
**逐句大白话解析：**
1. `int i = 1;`：`while` 循环的初始化必须写在外面。
2. `while (i <= 100) {`：如果 `i` 小于等于 100，就进入循环。
3. `sum = sum + i;`：累加。
4. `i++;`：**如果漏掉这行，`i` 永远是 1，就会死循环，终端卡死！**
5. `}`：循环体结束，跳回第 2 步继续判断。

## 📖 第二部分：嵌套循环（九九乘法表）

### 1. 什么是嵌套循环？
一个循环里面，还套着另一个循环。
**核心规则：外层循环每走 1 步，内层循环就要老老实实走完一整圈。**

### 2. 九九乘法表代码
```c
#include <stdio.h>

int main() {
    for (int i = 1; i <= 9; i++) {           // 外层：控制行
        for (int j = 1; j <= i; j++) {       // 内层：控制列
            printf("%d*%d=%-2d  ", j, i, i*j); 
        }
        printf("\n");                         // 换行
    }
    return 0;
}
```
**逐句大白话解析：**
1. `for (int i = 1; i <= 9; i++)`：`i` 代表“行号”，从第 1 行跑到第 9 行。
2. `for (int j = 1; j <= i; j++)`：`j` 代表“列号”。**为什么是 `j <= i`？** 因为第 1 行只有 1 列，第 2 行有 2 列，第 `i` 行必须有 `i` 列。
3. `printf("%d*%d=%-2d  ", j, i, i*j);`：打印算式。`%-2d` 是排版神器，意思是“左对齐，占 2 个字符宽度”，这样所有等号都能对齐。
4. `}`（内层结束）：内层循环结束，说明“一行”打印完了。
5. `printf("\n");`：**这行必须写在内层循环外面、外层循环里面！** 如果写在内层，每个算式都会换行。
6. `}`（外层结束）：第 1 行到第 9 行全部打完。

## 🌐 第三部分：HTML 进阶（图片、链接、表格与CSS）

### 1. 超链接
```html
<a href="https://www.baidu.com" target="_blank">点击去百度</a>
```
- `<a>`：超链接标签。
- `href`：目标网址。
- `target="_blank"`：在新标签页中打开。

### 2. 图片
```html
<img src="图片链接" alt="图片描述" width="200">
```
- `<img>`：自闭合标签（没有结束标签）。
- `src`：图片的路径或网址。
- `width`：宽度。

### 3. 表格
```html
<table border="1">
    <tr><th>科目</th><th>成绩</th></tr>
    <tr><td>C语言</td><td>95</td></tr>
</table>
```
- `<table>`：表格容器，`border="1"` 加边框。
- `<tr>`：行（Table Row）。
- `<th>`：表头单元格（粗体居中）。
- `<td>`：普通单元格（Table Data）。

### 4. 初步 CSS 样式
写在 `<head>` 标签里：
```html
<style>
    body { background-color: #f0f0f0; } /* 灰色背景 */
    h1 { color: blue; }                 /* 标题蓝色 */
</style>
```

   - `cd sum_while.c` 会报错 `No such file or directory`，因为 `cd` 后面只能跟目录。要运行文件，应当先 `cd` 进入文件所在的目录，再执行编译和运行。

   - 输入 `cd 04` 然后按 `Tab` 键，系统会自动补全为 `cd 04_C_Class/`。
   - 如果按两次 `Tab` 没反应，只是把所有可能的名字列出来，说明你输入的开头不够唯一，**多输入几个字符，让它变成唯一的，再按 `Tab` 就行了**。
3. **Copilot（AI 助手）幽灵代码**
   - 灰色斜体代码是 AI 的预测，按 `Tab` 会填进去。**大一基础阶段强烈建议卸载或禁用，以免丧失独立思考能力，蓝桥杯考场没有 AI！**
