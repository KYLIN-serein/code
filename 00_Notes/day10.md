## 📖 第一部分：结构体基础（将零散数据打包）

**工程背景**：在真实项目中，一个实体（如员工、装备）通常包含多个不同类型的属性（ID、名字、工资）。结构体允许我们将这些数据打包成一个整体。

### 1. 核心代码 (`struct_basic.c`)
```c
#include <stdio.h>
#include <string.h>

// 1. 定义结构体类型（画图纸）
struct Employee {
    int id;           
    char name[20];    
    double salary;    
};

int main() {
    // 2. 按照图纸，造出一个具体的变量（盖房子）
    struct Employee emp1;
    
    // 3. 赋值
    emp1.id = 1001;
    strcpy(emp1.name, "张三"); // 重点！
    emp1.salary = 8500.50;

    printf("工号: %d, 姓名: %s, 薪水: %.2f\n", emp1.id, emp1.name, emp1.salary);
    return 0;
}
```

### 2. 硬核解析与坑点
- **`.`（点号）操作**：用于直接访问结构体变量里的成员。
- **⚠️ 字符数组赋值坑**：`emp1.name = "张三";` 是**绝对错误**的！因为数组名是常量地址，不能被赋值。必须使用 `<string.h>` 里的 `strcpy(emp1.name, "张三");` 进行内存拷贝。

## 📖 第二部分：结构体指针（工程高效传参）

**工程痛点**：如果在函数里直接传结构体变量，电脑会复制整份数据，极度浪费内存。必须传指针（地址）。

### 1. 核心代码 (`struct_pointer.c`)
```c
#include <stdio.h>

struct Employee {
    int id;
    double salary;
};

// 接收结构体的地址
void raiseSalary(struct Employee *p) {
    // 使用 -> 顺着地址修改原数据
    p->salary = p->salary * 1.1; 
}

int main() {
    struct Employee emp1 = {1001, 10000.0}; 
    
    // 传入地址 &
    raiseSalary(&emp1);
    
    printf("涨薪后: %.2f\n", emp1.salary);
    return 0;
}
```

### 2. 硬核解析：`&` 与 `*` 以及 `->`
- **`struct Employee *p`**：这里的 `*` 是类型标签，说明 `p` 是一个专门存 `Employee` 地址的指针。
- **`&emp1`**：获取 `emp1` 在内存里的真实地址（门牌号）。
- **`p->salary`**：**（极其重要）** 因为 `p` 只是个地址，必须用 `->`（箭头）顺着地址找到对应的成员。它完全等价于 `(*p).salary`。

## 💻 第三部分：洛谷实战——P1008 三连击（枚举与计数板）

**核心思想**：暴力枚举（穷举），用数组做“计分板”统计 1-9 出现的次数。

### 1. 核心代码 (`P1008.c`)
```c
#include <stdio.h>

int main(){
    // A 最小 123，最大 329（因为329*3=987，再大 C 就四位数了）
    for(int A = 123; A <= 329; A++){
        int B = A * 2;
        int C = A * 3;

        // 准备一个计分板，全初始化为0
        int count[10] = {0};

        // 拆解 A 的百位、十位、个位
        count[A / 100]++;
        count[(A / 10) % 10]++;
        count[A % 10]++;

        // 拆解 B
        count[B / 100]++;
        count[(B / 10) % 10]++;
        count[B % 10]++;

        // 拆解 C
        count[C / 100]++;
        count[(C / 10) % 10]++;
        count[C % 10]++;

        int callo = 1; // 标志位：假设这组数字是合法的

        // 检查：如果出现过 0，直接淘汰
        if(count[0] > 0){
            callo = 0;
        }

        // 检查 1-9：只要有一个格子不是 1（多了或少了），直接淘汰
        for(int i = 1; i < 10; i++){
            if(count[i] != 1){
                callo = 0;
                break;
            }
        }

        // ⚠️ 致命坑点：这里必须是 == 判断，不能是 = 赋值！
        if(callo == 1){
            printf("%d %d %d\n", A, B, C);
        } 
    }
    return 0;
}
```

### 2. 硬核解析
- **缩小枚举范围**：不需要9个for循环，通过 A 推算 B 和 C，循环范围直接缩小到 200 多次。
- **`count` 计数板**：`count[数字]++`，完美解决了数字重复和缺失的判断。
- **拆位公式**：百位 `/100`，十位 `(x/10)%10`，个位 `%10`。
- **标志位 `callo`**：先默认是真的（1），一旦发现不符合条件，立刻改为假（0）并 `break` 提前结束检查。

## 🧠 今日踩坑记录（考前必看）

1. **字符数组不能用 `=` 赋值**，必须用 `strcpy`。
2. **结构体指针用 `->`** 访问成员，普通结构体用 `.` 访问。
3. **`=` 与 `==` 的致命区别**：在 `if(callo = 1)` 中，`=` 是赋值，会导致程序无视条件全盘输出；`callo == 1` 才是判断。为防手误，可写成 `if (1 == callo)`。
4. **数组名即地址**：`scanf("%s", str)` 不需要加 `&`，因为 `str` 已经是地址。
