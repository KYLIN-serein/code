## 📖 第一部分：一维数组基础与输入

### 1. 数组的概念（盖房子与开房门）
- `int arr[5];`：申请 5 个整数的空间。这相当于盖了 5 个房间，房间号（下标）从 0 到 4。
- **数组长度 vs 最大下标**：长度是 5，但最大下标是 4（长度-1）。写 `arr[5]` 会数组越界，导致程序崩溃（Segmentation fault）。
- **初始化**：`int arr[5] = {10, 20, 30, 40, 50};`

### 2. 让用户输入数组的值（经典用法）
```c
int arr[5];
for (int i = 0; i < 5; i++) {
    scanf("%d", &arr[i]); // ⚠️ 千万别漏 & 
}
```
**逐句解析：**
- `for` 循环 5 次，每次负责打开一个房间。
- `scanf("%d", &arr[i]);`：把输入的数字存进第 `i` 个房间。**必须加 `&`**（取地址符），因为没有地址，电脑不知道该往哪里塞数据。

### 3. 输出数组的值
```c
for (int i = 0; i < 5; i++) {
    printf("%d ", arr[i]); // 打印不需要加 &
}
```

## 🧠 第二部分：底层机制（极其重要！）

### 1. `scanf` 与空格/回车的“爱恨情仇”
- **空格是分割键**：`scanf("%d")` 读取一个整数后，如果遇到空格、Tab或回车，它就知道“这个数字读完了”，会**自动把空格吃掉，然后结束本次读取**。
- **一次回车即可**：用户不需要每个数字敲一次回车，只要中间用空格隔开（如 `10 20 30 40 50`），最后敲一次回车，循环里的 5 个 `scanf` 就能完美接力读完。
- **避坑**：如果用逗号分隔（`10,20`），`scanf` 会报错罢工。**只能用空格或Tab**。

### 2. 程序执行流程与 `scanf` 的“阻塞”
- `printf` 是“社畜”，打完字立刻走人，不管你看没看。
- `scanf` 是“守门员”，**只要键盘没有输入，它就会一直堵在那里（阻塞机制），导致整个程序暂停**，直到你按下回车。
- **正确流程**：先 `printf` 提示用户输入，紧接着 `scanf` 等输入，循环往复。

## 💻 第三部分：实战练习（自己独立完成）

### 任务：输入 5 个数字，找出最大值
```c
#include <stdio.h>

int main() {
    int arr[5];
    
    printf("请输入 5 个整数（用空格分隔）:\n");
    for (int i = 0; i < 5; i++) {
        scanf("%d", &arr[i]); // 接收输入
    }

    int max_val = arr[0]; // 先假设第一个数是最大的
    for (int i = 1; i < 5; i++) { // 从第二个开始比
        if (arr[i] > max_val) {
            max_val = arr[i]; // 如果遇到更大的，就更新最大值
        }
    }

    printf("这5个数中的最大值是: %d\n", max_val);
    return 0;
}
```
**逻辑解析**：打擂台法。先设定第一个数是擂主（max_val），然后从第二个数开始挑战，谁大谁就穿上擂主的衣服，最后留下来的就是最大的。

## 🧠 第四部分：今日踩坑记录（考前必看）

1. **漏掉 `&` 导致段错误**：`scanf("%d", arr[i]);` 是不行的，必须写 `&arr[i]`。
2. **`bin` 目录没有创建导致链接报错**：报 `ld returned 1 exit status` 或 `cannot find bin/xx`，先执行 `mkdir -p bin`。
3. **越界问题**：循环条件务必写成 `i < 5`（不是 `i <= 5`）。
